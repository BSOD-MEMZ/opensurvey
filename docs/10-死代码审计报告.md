## 五、明确**不是**死代码（避免误删）

审计过程中这几类被脚本判为"未使用"，但**复核后确认是在用的**：

| 项 | 为什么不是死的 |
| --- | --- |
| 25 个题型缩略图 `question-type-snapshot/*.svg` | 通过 `snap('<type>')` **拼字符串**引用，静态搜索看不到 |

| `sk-theme` 类 | 写在 `render/index.html` 的 `<body>` 上（脚本最初漏扫 `.html`） |
| `w-e-text-container` | wangEditor 的**第三方类名**，通过 `:deep()` 覆写 |
| `LAYER_SPEC` / `createShapes` 等 | 被 `SekaiBackground/index.vue` 引用（脚本最初漏扫 `.vue`） |
| `IconResolver` 自动导入的 `i-ep-*` | `unplugin-icons` 在构建时注入，源码里没有 import |

**这也是为什么这份报告不直接给"删除脚本"** —— 静态分析在动态引用面前不可靠，必须人过一遍。
