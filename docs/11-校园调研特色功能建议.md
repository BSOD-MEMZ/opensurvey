# 校园调研特色功能建议

> 场景：高中研究性学习课题的问卷调查
> 前提：这套平台已完成题型补齐（25 种）、pjsk 主题、去品牌化
> 编写时间：2026-10-06

---

## 零、先说一个判断

研究性学习的成败**不在功能多不多，在样本干不干净**。

一个课题组通常只有 3–6 个人、2–4 周时间，能收到几十到几百份。
研究报告里最容易被老师问倒的一句话是：**"你怎么证明这些数据是有效的？"**
—— 如果收上来 200 份，其中 60 份是同一个班的人互相抄着填的，这份报告就废了。

所以下面的建议里，我把「数据质量」排在「花哨功能」前面。
考试模式、抽奖红包、模板库这些，对研究性学习基本没用。

---

## 一、今天就零开发能做的三件事

现有能力已经能覆盖，不用改代码：

| 做什么 | 怎么做 |
| --- | --- |
| **换成学校视觉** | 编辑器「皮肤设置」→ 头图上传校徽/校园照；主题色改校色；自定义 CSS 里加校徽水印 |
| **班级分发** | 「渠道」功能就是现成的 —— 每个班建一个渠道，各自生成二维码贴班级群，统计页能按渠道看回收量 |
| **附问卷原件** | 编辑器里截图或打印空白问卷，研究报告的「附件」部分要用 |

> 渠道那一条**特别值得用起来**。项目本来就有多渠道投放、各渠道分别计回收量，
> 正好等价于"按班分发"。这是最省力的班级维度方案（见下文建议 A）。

## 二、核心建议（按性价比排序）

### A. 把「班级」做成一等公民 ★★★★★

**为什么**：中国中学的组织方式是「年级 → 班级」，这是校园调研和通用问卷最大的差别。
问卷星没有这个概念，你得手工加一道"你哪个班"的题，然后回来手动分组。

**怎么做**（推荐第二种，几乎零成本）：

| 方案 | 说明 | 工作量 |
| --- | --- | --- |
| A1 填答者自选 | 问卷加一个内置的「班级」字段，从预设班级列表选 | 中 |
| **A2 一班一码** | **每个班一个投放链接/二维码，自动带班级标签**。填答者完全无感 | **小** |

A2 的实现路径出人意料地顺 —— **复用已有的渠道机制**：
- 每个班 = 一个渠道（`channelId`）
- 生成班级列表 → 批量建渠道 → 每个渠道出一个二维码
- 数据表自动多一列「班级」；`SurveyResponse` 里 `channelId` 字段本来就存着

**要动的**：渠道的命名与批量创建界面（前端为主）、数据表里把 `channelId` 显示出来。

---

### B. 有效样本检测与剔除 ★★★★★

**为什么**：这是研究性学习最刚需、也是问卷星收费才给的能力。

**怎么做**（三条检测规则，都是纯计算）：

| 规则 | 判据 | 数据基础 |
| --- | --- | --- |
| 用时过短 | 总时长 < 题目数 × 阈值（比如每题 3 秒） | ✅ **已有** `SurveyResponse.diffTime`，数据表已在返回 |
| 直线作答 | 连续 N 道量表/矩阵题选同一个选项 | 需读 `data` |
| 规律作答 | 如 `1,2,3,4,5,4,3,2,1` 这类对称/循环模式 | 需读 `data` |

**关键**：检测出来还得**能剔除**。而当前平台**连单份答卷删除都没有**
（`surveyResponse` 模块只有 4 个提交接口）—— 所以这块必须和「答卷管理」一起做。

**要动的**：
- 服务端：新增答卷列表 / 详情 / 删除接口（目前完全空缺，见 `docs/01` §3.1）
- 新增一个「答卷质检」页：列出可疑答卷 + 剔除按钮
- 统计与导出时排除已剔除的答卷

**工作量**：中偏大，但**这是最值得投的一块**。

---

### C. 按维度交叉分析 ★★★★☆

**为什么**：研究性学习报告的核心章节就是「差异分析」——
「不同性别的手机使用时长有差异吗？」「重点班和普通班的睡眠时间有差别吗？」
问卷星把交叉分析放在付费版。

**怎么做**：
- 分题统计页加一个「分组维度」下拉（按班级 / 按性别 / 按年级 / 按任意单选题）
- 输出交叉表 + 堆叠柱状图
- 顺手把**矩阵 / 排序 / 滑块 / 比重**也接进分题统计（目前这 4 类在统计页是空白）

**要动的**：`dataStatistic` 的聚合管线（服务端）+ 统计页（前端）。
**工作量**：大。但这是"问卷星要花钱、我们有"的差别。

---

### D. 校园调研模板库 ★★★☆☆

**为什么**：降低启动成本。现在只有 4 套模板（普通/NPS/报名/投票），没有一套是校园调研。

**建议内置的课题模板**（都是高中研究性学习的常见选题）：
- 中学生手机使用与睡眠质量
- 中学生体育锻炼习惯
- 中学生饮食与健康
- 中学生心理健康 / 压力来源
- 中学生阅读习惯
- 零花钱与消费观
- 校园食堂满意度
- 选科意向调查

每套预置 10–15 道题（含矩阵量表题），改改就能用。

**要动的**：`server/.../template/surveyTemplate/survey/` 加 JSON（每套一个文件）。
**工作量**：小 —— 和现有 4 套模板同构，照着 `normal.json` 改。

---

### E. 匿名但有编号 ★★★☆☆

**为什么**：涉及手机、心理、早恋这类敏感话题时，学生不愿实名 —— 但填了假名的数据更糟。
课题组又需要防重复。

**怎么做**：
- 服务端为每份答卷生成一个**匿名编号**（如 `A-037`），并把班级带上
- 填答者看不到编号，课题组只看到「班级 + 编号」
- 去重靠浏览器指纹 / 登录态 / IP，而不是靠学号

**要动的**：答卷记录加两个字段（编号、班级），提交时生成。
**工作量**：小。

**注意**：不要做「学号白名单」—— 那等于让填答者实名，敏感话题下会显著降低真实性和回收率。

---

### F. 空白问卷样表导出 ★★★☆☆

**怎么做**：一键把问卷导出成可打印的空白样表（PDF 或排版好的 HTML）。
高中研究性学习报告通常要求在附件里附上**原始问卷**。

**要动的**：新增一个渲染出口，复用答题端的题干渲染。
**工作量**：小偏中。

---

### G. 一键生成报告草稿 ★★☆☆☆

**为什么**：最有"独一无二"的感觉，但工作量最大。

**怎么做**：把「样本量 + 各题统计 + 交叉表」拼成一份 Markdown/Word：
研究背景（模板占位）→ 研究方法 → 样本构成 → 数据呈现（含图表）→ 结论（模板占位）。

**要动的**：报表生成管线 + 文档模板。
**工作量**：大。建议放在最后，或者做成"只导出图表包"的轻量版。

---

## 三、建议的组合与顺序

| 阶段 | 做什么 | 解决的问题 |
| --- | --- | --- |
| **第一步** | A2 一班一码 + D 校园模板 + E 匿名编号 | 低成本，立刻让平台"像学校的" |
| **第二步** | 答卷管理（列表/详情/删除）+ B 有效样本检测 | 让数据可信 —— **这一步最关键** |
| **第三步** | C 交叉分析 + 矩阵/排序/滑块/比重接入统计 | 让报告能写出"差异分析" |
| **第四步** | F 空白样表导出、G 报告草稿 | 交付环节的加分项 |

**如果时间只够做一件事**：做第二步的**答卷管理 + 时长/直线作答检测**。
研究性学习的老师最认这个。

---

## 四、不建议做的

| 项 | 原因 |
| --- | --- |
| 考试模式 / 自动判分 | 和"调查研究"是两件事，工作量却是独立产品级的 |
| 抽奖 / 红包 | 校园调研用不上，还容易引来为奖品乱填的样本 |
| 排行榜 / 数据大屏 | 调研场景无意义 |
| 微信/QQ 登录 | 工作量大、要平台资质；学生对匿名链接接受度已足够 |
| 学号白名单强制实名 | **会显著降低敏感话题的真实性和回收率** |
