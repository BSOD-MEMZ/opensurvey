# 问卷星功能对齐复查

> 目标产品：问卷星（wjx.cn）式在线调查系统
> 复查时间：2026-10-05（第三轮，管理端换皮 + 去品牌化之后）
> **结论口径：只写实测过的**。每条都标了证据（代码位置 / 冒烟测试步骤 / 页面截图）。

---

## 零、一句话结论

「建问卷 → 发问卷 → 收答卷 → 出统计 → 导数据」这条主链路是**通的、可用的**，
账号、组织、逻辑编排、投放限制、脱敏导出、二维码这些配套都在。

但**「问卷星所有功能」仍然做不到**，差距集中在四块：

1. **题型**：13 种，问卷星是 30+。还差日期/时间/下拉/文件上传/图片题/计算题/比重题
2. **统计**：矩阵 / 排序 / 滑块三类新题型**不进分题统计图**（数据表和导出正常）
3. **考试模式**：整块没有（无标准答案、无自动判分、无成绩单）
4. **运营**：无抽奖/红包，无模板库（只有 4 套内置模板）

下面按「已有 / 半成品 / 缺失」三档列清楚。

## 三、缺失能力

### 3.1 题型缺口

| # | 缺失题型 | 说明 |
|---|---|---|
| 1 | 日期 / 时间 | 无 |
| 2 | 下拉选择 | 服务端无对应类型 |
| 3 | 文件上传题 | 上传接口有，但没包装成题型 |
| 4 | 图片单选 / 图片多选 | 选项带图，问卷星招牌题型之一 |
| 5 | 计算题 / 公式题 | 由其他题运算得出 |
| 6 | 比重题 / 分配题 | 多选项合计 100% |
| 7 | 矩阵填空 | 矩阵单选 / 量表已补，填空未做 |
| 8 | 格式预设校验 | 手机号 / 邮箱 / 身份证 / 网址 一键校验 |

### 3.2 数据能力

- **答卷详情查看、单份答卷编辑、单份删除**（问卷星可逐份改）
- **按条件筛选答卷**（如「只看选了 A 的答卷」）
- **开放式题目编码**（把主观回答归类打标）
- **交叉分析**（多题交叉制表）—— 上游 README 宣称有，实际没有
- 导出格式只有 XLSX；无 CSV / SPSS / PDF 报表
- 统计图类型少（无条形对比、折线趋势、填空词云）
- 无「多问卷合并分析」

### 3.3 考试 · 测评模式（整块缺失）

- 设置正确答案、每题分值
- 交卷后自动评分、总分与及格线
- 成绩单页面、排行榜
- 错题本、题目解析
- 限时答题 / 倒计时自动交卷（注：已有「作答时长限制」，但没有倒计时与强制交卷）

### 3.4 运营类

- **抽奖 / 红包** —— 缺失
- **模板库** —— 只有 4 套
- **多语言问卷** —— 无

### 3.5 账号与后台

- **修改密码 / 找回密码：没有**。`auth.controller.ts` 只有 `register / login / captcha / password/strength / verifyToken` 五个接口
- 个人资料编辑：无
- 组织架构 / 子账号：无（只有空间 + 角色）
- 操作日志 / 审计：无

## 四、建议的补齐顺序

按「实现成本 ÷ 用户感知」排序：

**P0 —— 把统计补齐，让现有题型闭环**
1. 矩阵 / 排序 / 滑块接入分题统计（矩阵按行×列展开、排序按名次拆解）
2. 题型枚举三处白名单（统计、导出、校验）同步维护，并加一条自检防止再漂移

**P1 —— 继续补题型**
3. 日期 / 时间 / 下拉（成本低，物料模式直接复用）
4. 文件上传题型包装（上传接口现成）
5. 图片单选 / 图片多选（要动选项数据结构，成本中等）
6. 格式预设校验（手机号 / 邮箱 / 身份证）

**P2 —— 数据能力**
7. 答卷详情查看 + 单份编辑 + 单份删除
8. 交叉分析页
9. 导出补 CSV（带 BOM，Excel 不乱码）

**P3 —— 考试模式与运营**
10. 正确答案 + 分值 + 自动评分 + 成绩单
11. 修改密码 / 个人资料
12. 模板库扩充

---

## 五、需要你拍板

1. **先补哪个 P0？** 我建议先做「矩阵 / 排序 / 滑块的分题统计」—— 现在最刺眼的一块缺口，
   而且不做的话这三类题在「分题统计」页里是空的，用户会以为数据丢了。
2. **要不要做交叉分析？** 它是问卷星使用率很高的分析手段，但需要一套独立的聚合管线，成本不低。
3. **考试模式要不要做？** 这一块是独立产品级的工作量（数据模型、答卷流程、成绩单都要改）。
