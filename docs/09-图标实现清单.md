## 1. 管理端功能图标 —— 图标字体

**字体**：`web/public/fonts/iconfont-mgmt.{woff2,woff,ttf}`
**定义**：`web/src/management/styles/icon.scss`（`@font-face` + 72 个 `.icon-xxx::before { content: '\eXXX' }`）
**来源**：阿里巴巴 iconfont 项目 `4263849`

**用法**：`<i class="iconfont icon-baocun"></i>`

**怎么换**：

| 想做什么 | 怎么做 |
| --- | --- |
| 换单个图标的样子 | 去 iconfont 项目里改字形，重新下载字体覆盖 `public/fonts/iconfont-mgmt.*` |
| 换成别的图标库 | 换掉 `public/fonts/` 里的字体 + 改 `icon.scss` 的码位映射，**类名可以保持不变**（调用处不用动） |
| 换成内联 SVG | 参照第 3 类，把 `<i class="iconfont icon-xxx">` 换成 SVG 组件。调用点大约 34 处 |
| 新增一个字形 | 在 `icon.scss` 末尾加 `.icon-新名字::before { content: '\eXXX'; }` |

## 3. 题型调色板图标 —— 内联 SVG（**推荐优先改这类**）

**文件**：`web/src/management/pages/edit/modules/questionModule/components/QuestionTypeIcon.vue`（168 行）

**结构**：一个 `ICONS` 对象，`key` = 题型 `type`，`value` = SVG 内部标记字符串，模板里 `v-html` 渲染。

```js
const S = 'fill="none" stroke="currentColor" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"'

const ICONS = {
  radio: `
    <circle cx="6.5" cy="8" r="2.6" ${S}/>
    <path d="M12.5 8h7.5" ${S}/>`,
  ...
}
```

**25 个题型全覆盖**：text / textarea / date / time / select / upload / multi-fill / radio / checkbox /
binary-choice / radio-star / radio-nps / vote / image-radio / image-checkbox / proportion / cascader /
matrix-radio / matrix-scale / matrix-checkbox / matrix-input / sort / slider / section / calculation

**怎么换**：直接改 `ICONS` 里对应 key 的 SVG 内容。约定：

- viewBox 统一 `0 0 24 24`
- **不要写死颜色** —— 用 `${S}`（`stroke="currentColor"`），这样能自动跟随主题色
- 需要实心的地方写 `fill="currentColor" stroke="none"`
- 已定义好的 `S` 常量就是标准描边样式，复用它保持风格统一

**为什么用内联 SVG 而不是字体**：原 iconfont 里**根本没有**矩阵 / 排序 / 滑块 / 图片题这些字形，
且字体走远程 CDN。内联 SVG 能跟主题变色、可离线、加题型时不用再想办法搞字形。

## 4. 选项编辑小图标 —— 内联 SVG 组件

**文件**：`web/src/materials/questions/widgets/EditOptions/ExtraIcon/index.vue`

两个图标：`add-square`（添加选项）、`add-multi`（批量选项）。

颜色是**硬编码**的：`getColor() { return '#3FD0BD' }`（青绿）。要跟随主题的话，把 `:fill="getColor"`
换成 `fill="currentColor"` 并在外层设 color。

**怎么换**：改这个组件里的 `<svg>` 内容。

## 5. Element Plus 图标 —— unplugin-icons 自动导入

**配置**：`web/vite.config.ts` 里的 `IconsResolver`（第 82/93 行附近）

**用法**：直接写 `<i-ep-upload />`，组件会在构建时自动导入，**不需要 import**。

**用到的 22 个**：

| 图标 | 次数 | 图标 | 次数 |
| --- | --- | --- | --- |
| `i-ep-question` | 9 | `i-ep-sort` | 1 |
| `i-ep-circle` | 4 | `i-ep-search` | 1 |
| `i-ep-plus` | 3 | `i-ep-rank` | 1 |
| `i-ep-upload` | 2 | `i-ep-monitor` | 1 |
| `i-ep-remove` | 2 | `i-ep-minus` | 1 |
| `i-ep-delete` | 2 | `i-ep-loading` | 1 |
| `i-ep-connection` | 2 | `i-ep-iphone` | 1 |
| `i-ep-close` | 2 | `i-ep-copy` | 1 |
| `i-ep-view` / `top` / `bottom` | 各 1 | `i-ep-sort-up` / `sort-down` | 各 1 |
| `i-ep-check` | 1 | | |

**怎么换**：

- 换某个图标：把 `<i-ep-xxx />` 改成别的名字即可。所有可用名见
  [Element Plus 图标列表](https://element-plus.org/zh-CN/component/icon.html)（前缀去掉 `El`、驼峰转连字符，
  如 `ElArrowDown` → `i-ep-arrow-down`）
- 换成别的图标库：改 `vite.config.ts` 里的 `IconsResolver` 配置（换成 `@iconify-json/tabler` 之类）

## 9. 题型缩略图 —— SVG 文件

**位置**：`web/public/imgs/question-type-snapshot/*.svg`（25 个，与题型一一对应）
**引用**：`web/src/management/config/questionMenuConfig.js` 里 `snapshot: snap('<type>')`
**用途**：调色板里鼠标悬停时的预览图

**怎么换**：

| 方式 | 做法 |
| --- | --- |
| 单个替换 | 直接改或替换对应的 `.svg`（保持 120×80 左右的比例即可） |
| 全部重生成 | 改 `docs/brand/gen-question-snapshots.mjs` 里的 `TYPES` 数组，然后跑它（需要 chromium） |
| 换成位图 | 把 `questionMenuConfig.js` 里的 `snap()` 改成指向 `.webp`，注意路径也要改 |

生成脚本里面的胶囊标签是**右对齐**的 —— 因为中文字宽靠估算会重叠，右对齐最稳。

## 换图标时的一句话建议

- **优先改第 3、6 类（内联 SVG）**：不依赖字体文件、能跟随主题色、离线最稳、可随时加
- **第 1、2 类的字体图标**：如果只是换外观，改 `content` 码位或用别的字体覆盖，
  **类名别动** —— 这样调用处一行都不用改
- 换完建议跑一遍 `npm run build-only` 确认没漏（这个项目不会因为图标缺失而报错，
  只会静静显示成空白或豆腐块）
