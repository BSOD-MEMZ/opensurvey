## 一、导航统一（对应 I11 / I12 / I13 / I28）

### 改造前

同一套管理端并存 **4 种导航**，编辑页三层叠加：

| 组件 | 位置 | 出现页面 |
|---|---|---|
| `TopNav` | 顶部 | 问卷列表、下载中心 |
| `LeftMenu` | 左侧 80px 竖排 | 编辑、投放、统计 |
| `ModuleNavbar` | 编辑页顶部 | 问卷编辑/问卷设置/皮肤设置 + 预览/历史/保存/发布 |
| 页内 tab | 页面中部 | 内容/逻辑、内容页/结果页、数据列表/分题统计/答卷管理 |

### 改造后

**不再有左侧竖排栏**，收敛为「一条全局顶栏 + 一条问卷内顶栏 + 页内 tab」：

1. **全局顶栏 `TopNav`**（所有登录后页面恒定）
   `Logo ｜ 问卷列表 · 下载中心 ……………… 您好,xx · 退出`
2. **问卷内顶栏 `SurveyNav`**（进入某份问卷后出现）
   `← 返回 ｜ 问卷标题 ｜ 问卷编辑 · 问卷设置 · 皮肤设置 · 投放问卷 · 数据统计 ｜ 预览 保存 发布`
   —— 原来散在 `LeftMenu`（编辑/投放/统计）和 `ModuleNavbar`（编辑/设置/皮肤）的入口**合并到同一层**，共 5 个 tab。
3. **页内 tab 保留**（页面局部，不再算一层导航）：编辑页 `内容设置/逻辑设置`、皮肤页 `内容页/结果页`、统计页 `数据列表/分题统计/答卷管理`。

### 文件变更

- **新增** `components/SurveyNav.vue`
- **删除**（已被取代，避免死代码）：`components/LeftMenu.vue`、`pages/edit/components/ModuleNavbar.vue`、`pages/edit/modules/generalModule/{NavPanel,BackPanel,TitlePanel}.vue`、`pages/publish/components/Navbar.vue`、`pages/publish/PublishPage.vue`
- **改造** `components/TopNav.vue`（玻璃化 + 修 `default-active`）、`pages/edit/index.vue`（承接 ModuleNavbar 的校验逻辑）、`pages/publish/ChannelPage.vue`、`pages/analysis/AnalysisPage.vue`
- **路由** `publish` 改为重定向到 `channel`（两个"投放页"合一）

## 六、登录页重排（后续追加）

第一版把登录/注册拆成两个模式后，卡片排版仍显散乱。根因是**三套互不对齐的左边界**：

| 元素 | 改前左边界 | 原因 |
|---|---|---|
| el-form-item 的标签 | 卡片 x+0 | `.login-form { padding: 60px 60px 60px 0 }` 左侧内边距是 0 |
| el-form-item 的输入框 | 卡片 x+100 | `label-width: 100px` |
| `.mode-switch` / `.switch-tip` | 卡片 x+60 | 后加的两条 `padding-left: 60px` |

再加上：强度条单独占一个 `label=""` 的表单项（白留 100px 空档）、按钮只有 204px 且居左、`margin-top: -150px` 硬顶定位。

**重排做法**：

1. 表单改为 `label-position="top"`，标签在输入框上方 —— 消灭 100px 标签沟槽。
2. 强度条移进「密码」表单项内部，紧贴密码框，不再单独占位。
3. 卡片统一 `padding: 36px 44px 32px`，模式切换/输入框/按钮/底部提示共用同一条内容轴。
4. 模式切换改成整行分段控件（灰底轨道 + 白色滑块），一眼看出当前在哪一边。
5. 按钮改全宽 44px；底部切换链接居中；Enter 可直接提交。
6. 布局改 `flex` 撑满（顶栏 flex:none + 内容 flex:1），去掉 `margin-top: -150px`；窄屏卡片自动收窄并允许滚动。
7. 清掉未使用的 `.tips` 样式。

**实测（CDP 量盒子，非目测）**：

```
[1440x900] hScroll=0
  card       500..940 (w=440)
  modeSwitch 544..896 (w=352)
  firstInput 544..896 (w=352)
  submit     544..896 (w=352)
  switchTip  544..896 (w=352)
[1280x800] 注册模式：3 个输入框均 464..816，hScroll=0
[420x780]  卡片 24..396，各元素均 68..352，hScroll=0
```

四个元素的左右边界完全重合（544 = 卡片 500 + 内边距 44），窄屏无横向溢出。
